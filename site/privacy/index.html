Privacy Policy

Last updated: March 24, 2026

Overview

Magic Powers is an open-source Claude Code plugin. This privacy policy describes how the project operates with respect to user data.

Data Collection

Magic Powers does not collect, store, or transmit any personal data. The plugin consists of markdown files (agents, skills, commands) that run locally in your AI coding tool.

This website (magic-powers.pmai.space) does not use analytics, cookies, or tracking of any kind.

Third-Party Services

Magic Powers integrates with the following optional third-party tools, each with their own privacy policies:

Google Stitch SDK — used optionally for UI design generation. Subject to Google's privacy policy.
Pencil (pencil.dev) — used optionally for MCP canvas design. Subject to Pencil's privacy policy.
npm — the package is distributed via npmjs.com. Subject to npm's privacy policy.

Magic Powers itself does not send any data to these services — usage is initiated explicitly by the user.

Open Source

Magic Powers is fully open source under the MIT License. All code is publicly available at github.com/kienbui1995/magic-powers for inspection.

Contact

For privacy-related questions, open an issue at github.com/kienbui1995/magic-powers/issues.
